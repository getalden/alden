Draft my review, and Draft with Alden. When a model is set up, **Draft my review** (beside Comments in the briefing, and in the Comments drawer) asks it, in one call within your budget caps, for comments on the PR's places to look, Alden's own checks included, and the model's findings, wherever the briefing drafted none: up to eight, each on its line or as a general note linking there, skipping places that already have a draft or a comment of yours on GitHub near them (and saying how many). They're Alden's drafts like the briefing's: keep, edit or drop each, never sent untouched, never an approval. It says what it made and what it cost, or why it couldn't. **Draft with Alden** in every comment and reply box asks for one comment (or a reply to the thread), from the code there or from what you've written so far, and puts it in the box for you to edit: Use it or Keep mine when you'd written something, Undo, and Cancel while it runs. It saves nothing; what you save is yours. Neither runs on a PR with text aimed at AI reviewers, and the PR's own text goes to the model fenced as data, never instructions. In a terminal, `alden comment <pr> --draft`. Usage stats count a saved comment that Alden drafted (never its text).
