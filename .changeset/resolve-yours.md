Alden resolves only threads you started. GitHub lets anyone with write access resolve any thread, but resolving someone else's question for them is theirs to do: in the Comments drawer, a thread someone else started says "ana's to resolve" instead of offering **Resolve when sent**, and `alden comment <pr> --resolve` on one says why and suggests a reply. Replies stay open to every thread you can see, yours or not, as GitHub allows.
