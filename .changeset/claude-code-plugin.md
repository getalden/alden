The Claude Code plugin: `/alden:review` reviews a PR or your local changes the way you would, with Alden's checks,
the callers outside the diff and your memory, and records which places you found useful; `/alden:queue` and
`/alden:remember` too. Install with `claude plugin marketplace add getalden/alden` and
`claude plugin install alden@getalden`.
