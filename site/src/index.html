The review companion that knows what you look for.

Alden ranks the PRs waiting on you and writes each one a briefing with the callers and checks the diff leaves out. When someone answers your comments, the PR comes back under Your turn. Every place you mark useful or not useful teaches it a little more about how you review.

02 / learns you

In week one it flags a lot. By week six it flags what you would.

Mark a place useful and Alden gives that kind of flag more weight next time. Mark it not useful and it backs off. Keep opening PRs in one area of the code, or from one author, bot or AI agent, ahead of where Alden ranked them, and PRs like that rank higher. A person's PR that Claude Code, Copilot, Cursor or another agent wrote counts as that agent's too, and its row says how Alden knew. Everything it learns is listed, with where it came from, and you can edit or forget any of it.

    03 / yours

    Runs on your machine, on your terms.

    Alden works from your local clone and your own GitHub sign-in. You pick the model and decide how much it can spend.

    where
    On your machine. The queue, briefings and what Alden learns about you stay in ~/.alden.
    github
    Your own sign-in. Alden reads PRs and posts only what you send: the comments you write in Alden go to GitHub as one review when you send it.
    model
    Your Anthropic or OpenAI key, Bedrock, Vertex, Foundry or a local model through Ollama. Pick it per PR, ask it a question about a PR, or run checks only. No key? Alden Cloud is planned, with a waitlist.
    drafts
    Alden can draft comments on the places it flagged, in a tone you pick: terse, concise, detailed or teaching. Each one waits for you to keep, edit or drop it; none is sent untouched.
    spend
    Caps per briefing and per day, $0.50 and $10 by default, checked before every call.
    source
    Open source when the beta ends. The single-developer app stays free.
    04 / install

    Install it now. It's free during the beta.

    Alden is in open beta: anyone can install it. Pick one of four ways, then open the app or run alden: it signs you in with GitHub, asks how Alden should think, and shows your queue. Full steps are in Getting started.

    Desktop app macOS

    Signed and notarized, for Apple silicon and Intel. Your queue in a window and the menu bar, and the alden command too.

    brew install --cask getalden/tap/alden-desktop

    Or download the .dmg from the releases page.

    Homebrew macOS · Linux

    The alden command as a standalone binary. Needs nothing else.

    brew install getalden/tap/alden

    npm Node 22.13+

    During the beta, releases are published under the next tag.

    npm install -g alden@next

    Binary macOS · Linux · Windows

    For macOS (Apple silicon, Intel), Linux (x64, arm64) and Windows (x64). Unpack it and put alden on your PATH.

    Download a binary

    Then

    alden                # sign in, pick a model, then your queue, in the terminal
alden queue          # the PRs waiting on your review, ranked
alden review 1       # a briefing on #1
alden ask 1 "Is the retry safe?"   # a question about it, to your model
alden ui             # or all of it in your browser

    In Claude Code

    /plugin marketplace add getalden/claude-plugin
/plugin install alden@getalden

    Then /alden:review and /alden:queue. Alden itself must be installed and signed in first. See Claude Code plugin.
